# Target Account Outreach Plan (Next 10)

## Goal
Build a ranked top-10 pipeline of likely design partners for the finance POC and start high-probability conversations first.

## Steps
1. Populate `docs/target-account-list-template.csv` with 10 real candidates.
2. Score each candidate using `docs/target-account-scoring-model.md`.
3. Sort by `total_score` descending.
4. Start outreach with Tier A candidates first.

## Recommended cadence
- Day 1: score + prioritize list
- Day 2: send first outreach wave (3 accounts)
- Day 4: follow-up wave + second outreach wave (3 accounts)
- Day 7: review responses and update priority stack

## Minimum tracker fields to keep current
- `total_score`
- `priority_band`
- `next_action`
- `target_date`
- `status`

## Status definitions
- `prospecting`
- `contacted`
- `discovery_scheduled`
- `qualified`
- `pilot_kickoff_scheduled`
- `not_now`

## Success criteria
- 10 accounts scored
- 5+ initial contacts sent
- 2+ discovery calls booked
- 1+ pilot kickoff candidate identified
