# MCP Gateway Pilot Brief

## Title
**API-First, AI-First, Agent-First Control Plane for Finance Operations**

## One-line positioning
MCP Gateway is an **API-first agent control plane** that helps finance teams run AI agents safely across business systems with policy, approvals, and auditability.

## Why this pilot exists
Most finance automation tools are still UI-first and workflow-fragmented. Agents need secure, policy-governed API access to deliver real operational value.

This pilot proves:
1. AI agents can execute finance workflows safely.
2. Governance controls prevent unauthorized actions.
3. Teams get measurable speed gains in close/reconciliation prep.

## Target pilot workflow
**Month-end close and reconciliation preparation** with:
- route planning over registered upstream APIs
- policy-gated actions
- optional approval checkpoint before execution
- audit-ready run outputs

## Pilot outcomes
- Faster close prep
- Better operational visibility
- Lower risk through explicit controls

## Success metrics
- Time-to-first-value ≤ 1 business day
- 30%+ reduction in manual close-prep effort
- 0 unauthorized action execution
- Audit export accepted by finance stakeholder

## Technical capabilities in pilot
- Tenant-scoped API tokens and scopes
- Policy rules (allow/deny by action/resource/tenant)
- Weighted and failover route planning
- Health-aware server selection
- Gateway metrics and run evidence

## What makes this different
- **API-first** (not UI-bolted API)
- **Agent-first** (designed for ChatGPT/Claude-style agent workflows)
- **Control-plane-first** (policy + approvals + auditability as core)

## Candidate fit
- Controller-led teams at SMB/mid-market companies
- Ops teams with accounting + spreadsheet stack complexity
- Organizations needing AI automation without compliance trade-offs
