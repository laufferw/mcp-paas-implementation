# Pilot Kickoff Agenda v1 (45 min)

## 0–5 min: Introductions and objective
- Pilot goal: prove governed agent workflow value in finance ops.

## 5–15 min: Current process mapping
- Walk through existing close/reconciliation flow
- Identify manual steps and bottlenecks

## 15–25 min: Control-plane walkthrough
- Token/scopes model
- Policy model
- Route planning and failover behavior
- Audit output model

## 25–35 min: Define pilot execution plan
- Workflow scope
- Data/system access
- Approval owner
- Output artifacts and review cadence

## 35–40 min: Success criteria lock
- Time-to-first-value
- Manual effort reduction target
- Unauthorized action target (zero)
- Audit usability acceptance

## 40–45 min: Next actions
- Setup steps and owner assignments
- Pilot run date
- Weekly check-in schedule
