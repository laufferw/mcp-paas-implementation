# Partner First Call Checklist

## Before call
- [ ] Review partner intake questionnaire
- [ ] Confirm target workflow (close/reconciliation)
- [ ] Prepare latest pilot artifacts
- [ ] Confirm demo environment is healthy

## During call
- [ ] Validate current workflow bottlenecks
- [ ] Confirm systems of record and API constraints
- [ ] Confirm approval and audit requirements
- [ ] Align pilot success metrics
- [ ] Confirm security/compliance expectations

## Decision gates
- [ ] Is partner workflow in-scope for current POC?
- [ ] Is API access sufficient for pilot?
- [ ] Is stakeholder owner assigned?
- [ ] Is 2–4 week pilot timeline acceptable?

## End-of-call outputs
- [ ] Agreed pilot objective
- [ ] Agreed success metrics
- [ ] Named owner on partner side
- [ ] Pilot kickoff date
